Os diretivos gerados (lido dos templates do CLI):
```typescript
@Directive({ selector: '[hlmInput]', ... }) export class HlmInput { }
@Directive({ selector: '[hlmLabel]', ... }) export class HlmLabel { }
```

DETALHE TÉCNICO IMPORTANTE (verificado em
`node_modules/@spartan-ng/cli/src/generators/base/generator.js` + `lib/styles/`):
os templates do CLI contêm tokens `spartan-input` / `spartan-label`, e o generator os
SUBSTITUI pelas classes Tailwind reais lidas de `style-vega.css` no momento da geração
(é por isso que `libs/ui/button/src/lib/hlm-button.ts` tem Tailwind inline e nenhuma
referência a `.spartan-button`). As classes `.spartan-*` NÃO existem em
`@spartan-ng/brain/hlm-tailwind-preset.css` — o `styles.css` deste projeto importa apenas
esse preset. Consequência: se um arquivo gerado ficar com a string literal `spartan-input`
ou `spartan-label`, a substituição FALHOU e o campo renderizaria sem estilo nenhum. A
Task 1 tem um critério de aceite explícito para isso.
